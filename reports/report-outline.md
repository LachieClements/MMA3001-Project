# Individual report outline
Target: 5–10 pages; references and appendices do not count toward the 10-page limit.
This is an outline, not completed analysis.

1. Engineering problem: context, motivation, intended use, scope and limitations.
2. Inputs, outputs and data: provenance/licensing, formats, units, domains,
   missing/invalid input policy, target meaning and measurement uncertainty.
3. Computational method: at least one taught numerical/ML technique;
   explanation, justification, assumptions, parameters and implementation.
4. Verification and validation: tests, condition grouping, development/test
   separation, metrics, acceptance criteria, leakage controls and limits.
5. Alternatives and performance: credible baseline comparison; accuracy,
   timing/profiling, relevant robustness/sensitivity and trade-offs; justify
   the selected solution using evidence.
6. Results and engineering interpretation: supported claims, errors by condition,
   failure cases, limitations, lessons learned and future improvements.
7. AI reflection: tools, tasks, approximate contribution, reasons for use,
   independent checks, student decisions, errors and impact on understanding.
8. References: dataset, methods, software and other material used.

Before submission: regenerate HTML docs; run tests and retain an actual test
report; verify a clean environment workflow; provide an accessible repository
link and zipped clone; prepare the 5-minute presentation and 3-minute Q&A.
